# Course notebooks

Eighteen executed notebooks for an undergraduate course in separation processes, built around benzene-toluene
(the ideal pair) and ethanol-water (the one with an azeotrope). Every notebook states its learning objectives,
prerequisites and study time, explains a key algorithm in plain Python ("Inside the algorithm", checked
against the library), and ends with exercises including an "Implement it yourself" task. Worked solutions are
in [`../solutions`](../solutions).

## Running the notebooks

- **Google Colab:** open any notebook from GitHub in Colab (e.g.
  `https://colab.research.google.com/github/ktwyw/engsep/blob/main/notebooks/03_binary_distillation_mccabe_thiele.ipynb`);
  the first cell installs `engsep` automatically.
- **Locally:** `pip install -e ".[notebooks]"`, then `jupyter lab`.

The notebooks are generated from `build_notebooks.py`: edit that file, then run
`python notebooks/build_notebooks.py` (or `... build_notebooks.py 05 07` for selected notebooks) to rebuild and
execute them. The data files are generated by `tools/make_course_data.py`, the README images by
`tools/make_images.py`.
